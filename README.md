# PB Zero Wiki — Community Knowledge Base

A community-maintained knowledge base for Point Blank Zero — weapon stats, map callouts, game mode guides, and strategy breakdowns.

**[Open PB Zero Wiki →](https://pbzerowiki.com)**

## What's Covered

- Every weapon with damage stats, effective range, TTK, and recommended attachments
- Map layouts with callout positions, spawn points, and objective locations
- Game modes with rule breakdowns, scoring mechanics, and strategy guides

## Site

Built with static HTML/CSS, served via Cloudflare Pages. No JavaScript framework, no ads, no tracking. Loads in under 500ms on cold cache.
